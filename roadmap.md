# Roadmap du Projet --- Versions 1 à 4

## Version 1 --- MVP (Produit Minimum Viable)

**Objectif : Application légère et fonctionnelle**

### Fonctionnalités

-   Authentification simple
-   CRUD complet sur les notes
-   Tags ou catégories
-   Format de texte ( Gras, Italique, barré, List, tableau. ....)
-   Sauvegarde locale + synchronisation cloud simple
-   Recherche basique des notes
-   Changement de vue ( List, Grid)

------------------------------------------------------------------------

## Version 2 --- Collaboration & Groupes

**Objectif : Interaction entre utilisateurs**

### Fonctionnalités

-   Création de groupes
-   Invitation de membres (email ou code)
-   Notes partagées avec permissions (Admin / Éditeur / Lecteur)
-   Édition collaborative
-   Historique des modifications
-   Notifications push

------------------------------------------------------------------------

## Version 3 --- IA Intégrée & Notes Intelligentes

**Objectif : Ajouter de la productivité avancée**

### Fonctionnalités

-   Génération de note à partir d'un prompt IA
-   Création automatique de todo-list dans une note
-   Résumé automatique
-   Nettoyage / reformulation
-   Recherche intelligente (vector search)
-   Suggestion automatique de titres

------------------------------------------------------------------------

## Version 4 --- Notes Avancées & Multimédia

**Objectif : Rendre l'expérience complète et multimodale**

### Fonctionnalités

-   Enregistrement vocal + transcription
-   Notes avec images, vidéos, PDF
-   Scan de documents (OCR)
-   Annotations sur images / PDF
-   Mode hors-ligne complet + sync automatique
-   Sauvegarde incrémentielle optimisée
